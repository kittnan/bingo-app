# บิงโกคลาสสิก (Web App)

เครื่องเรียกเลขบิงโก 75 ลูกธีมคาสิโน ติดตั้งลงคอมหรือมือถือได้ และใช้งานแบบออฟไลน์ได้หลังเปิดครั้งแรก

## ไฟล์ในชุดนี้

- `index.html` ตัวแอป
- `manifest.webmanifest` ชื่อแอป ไอคอน และสี สำหรับการติดตั้ง
- `sw.js` ทำให้แอปเปิดได้ตอนไม่มีเน็ต
- `icons/` ไอคอนแอป

## เอาขึ้นเว็บ (ฟรี เลือกอย่างใดอย่างหนึ่ง)

**Netlify Drop (ง่ายสุด ไม่ต้องใช้คำสั่ง)**
1. แตกไฟล์ zip ให้ได้โฟลเดอร์ `bingo-app`
2. เปิด https://app.netlify.com/drop แล้วลากโฟลเดอร์ทั้งโฟลเดอร์ไปวาง
3. รอสักครู่ จะได้ลิงก์ `https://ชื่อสุ่ม.netlify.app` (สมัครบัญชีฟรีเพื่อเก็บเว็บไว้ถาวรและเปลี่ยนชื่อลิงก์ได้)

**GitHub Pages**
1. สร้าง repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ (ให้ `index.html` อยู่ชั้นบนสุด)
2. ไปที่ Settings → Pages → Source เลือก branch `main` แล้วกด Save
3. ได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

> ต้องเปิดผ่านลิงก์ `https://` เท่านั้นถึงจะติดตั้งและใช้ออฟไลน์ได้ ถ้าดับเบิลคลิกเปิด `index.html` จากเครื่องตรง ๆ เกมเล่นได้ แต่จะติดตั้งไม่ได้

## ติดตั้งเป็นแอป

- **คอม (Chrome / Edge):** เปิดลิงก์ แล้วกดไอคอนติดตั้งที่ท้ายช่อง URL หรือเมนู ⋮ → ติดตั้งแอป
- **Android (Chrome):** เมนู ⋮ → เพิ่มลงในหน้าจอหลัก / ติดตั้งแอป
- **iPhone / iPad (Safari):** ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

เปิดแอปครั้งแรกตอนมีเน็ต หลังจากนั้นเปิดได้แม้ไม่มีเน็ต

## ความสามารถ

- กดปุ่ม "หมุน!" หรือ Space เพื่อสุ่มลูก มีโหมดหมุนอัตโนมัติ
- ปุ่ม "เต็มจอ" ขยายเวทีเต็มหน้าจอสำหรับฉายขึ้นโปรเจกเตอร์
- เกมที่เล่นค้างไว้ถูกบันทึกในเครื่อง ปิดแอปแล้วเปิดใหม่ก็เล่นต่อได้
- จอไม่ดับระหว่างเล่น (ในเบราว์เซอร์ที่รองรับ)

## แก้ไขแอปภายหลัง

ถ้าแก้ไฟล์ใด ๆ ให้เปลี่ยนค่า `VERSION` บรรทัดบนสุดของ `sw.js` (เช่น `bingo-v2`) แล้วอัปโหลดใหม่ เครื่องที่ติดตั้งไว้จะอัปเดตเองเมื่อเปิดแอปตอนมีเน็ต
